## 0. 通用约定

| 约定 | 规则 |
|------|------|
| ID | 客户端生成 UUID 字符串，全局唯一；表内主键 |
| 时间戳 | `long`，UTC epoch milliseconds；展示按设备时区 |
| 日期（无时间） | 语义为本地日；存储可用该地当日 00:00 的 epoch 或 ISO date 字符串，实现二选一后在 D2 固定——**本包默认 `date` 逻辑类型，实现层建议 ISO `YYYY-MM-DD` 字符串** |
| 钟表时间（节次） | `int` 分钟数（自本地 00:00 起），避免时区歧义 |
| JSON 列 | 逻辑类型为列表/对象；实现用 TEXT 存 JSON；校验在 Repository + ToolValidator |
| 软删除 | `isDeleted` 默认 false |
| 创建/更新时间 | 所有主实体含 `createdAt` / `updatedAt` |
| source | 枚举：`MANUAL` \| `AGENT` \| `IMPORT`（MVP 不用 IMPORT） |
| 隐私级 | `L` 仅本地；`M` 可能进入模型上下文（Agent 对话或工具结果）；`S` 敏感（API Key 等，禁止进模型/日志） |

**校验优先级**：UI 表单与 Agent `ToolValidator` **共用**下表规则；Agent 入库前必须同一套。

## 1. Semester（学期）

表：`semesters`

| 字段 | 类型 | 必填 | 默认 | 值域/校验 | 索引 | 隐私 | 说明 |
|------|------|------|------|-----------|------|------|------|
| id | String | 系统 | UUID | 非空 | PK | L | |
| name | String | 是 | — | 1–40 字 | — | M | 如「2026 春」 |
| week1Monday | Date | 是 | — | 必须为周一 | — | M | 第 1 教学周周一 |
| endDate | Date | 是 | — | ≥ week1Monday | — | M | 学期结束日（含） |
| isCurrent | Boolean | 是 | false | 同时仅建议一条 true | IDX | M | 课表默认学期 |
| isDeleted | Boolean | 是 | false | | IDX | L | |
| createdAt | Long | 是 | now | | — | L | |
| updatedAt | Long | 是 | now | | — | L | |

**业务规则**

- `isCurrent = true` 时，Repository 应将其他学期的 `isCurrent` 置 false（单当前学期）。
- 删除学期 → 级联软删其 PeriodSlot 与 Course（写 undo）。

## 2. PeriodSlot（节次时段）

表：`period_slots`

| 字段 | 类型 | 必填 | 默认 | 值域/校验 | 索引 | 隐私 | 说明 |
|------|------|------|------|-----------|------|------|------|
| id | String | 系统 | UUID | | PK | L | |
| semesterId | String | 是 | — | 必须存在且未删 | IDX | L | FK → Semester |
| periodIndex | Int | 是 | — | 1–12 | 复合 IDX | M | 第几节 |
| startMinutes | Int | 是 | — | 0–1439 | — | M | 如 8:00 → 480 |
| endMinutes | Int | 是 | — | > startMinutes，≤ 1439 | — | M | |
| isDeleted | Boolean | 是 | false | | L | | |
| createdAt / updatedAt | Long | 是 | now | | L | | |

**业务规则**

- 同一 `semesterId` 内 `periodIndex` 唯一（未删）。
- 相邻节次允许重叠时间（不强制），但 UI 可提示。

## 3. Course（课程）

表：`courses`

| 字段 | 类型 | 必填 | 默认 | 值域/校验 | 索引 | 隐私 | 说明 |
|------|------|------|------|-----------|------|------|------|
| id | String | 系统 | UUID | | PK | L | |
| semesterId | String | 是 | — | 存在且未删 | IDX | L | |
| name | String | 是 | — | 1–60 字 | IDX（搜索） | M | |
| teacher | String? | 否 | null | ≤ 40 字 | — | M | |
| location | String? | 否 | null | ≤ 80 字 | — | M | |
| weekday | Int | 是 | — | 1–7（1=周一） | 复合 IDX | M | |
| periodStart | Int | 是 | — | ≥1，且学期存在该节次 | — | M | |
| periodEnd | Int | 是 | — | ≥ periodStart，≤12 | — | M | |
| weeksSpec | String | 是 | — | 见下方语法 | — | M | 周次集合 |
| isBiweekly | Boolean | 是 | false | | — | M | |
| biweeklyOdd | Boolean? | 否 | null | isBiweekly=true 时必填 | — | M | true=单周 |
| reminderOffsets | List\<Int\> | 否 | `[10]` | 每项 0–10080；最多 3 个 | — | M | 相对上课开始的分钟数 |
| colorToken | String | 否 | `c1` | c1–c8 | — | L | 预设色 |
| isDeleted | Boolean | 是 | false | | IDX | L | |
| createdAt / updatedAt | Long | 是 | now | | L | | |
| source | Enum | 是 | MANUAL | | L | | |

### weeksSpec 语法（逻辑）

- 逗号分隔：单项或闭区间
- 例：`1-16`、`1,3,5-8`、`2-16/2` 不支持（单双周用 `isBiweekly`）
- 解析后 week ∈ [1, 学期最大周]
- 非法 → 校验错误 `VALIDATION_ERROR`

**业务规则**

- `periodEnd` 对应节次的 `endMinutes` 决定投影结束时间。
- 更新 Course 影响所有未来/当前匹配周次投影；MVP 不提供「仅改下周」。

## 4. Event（日程）

表：`events`

| 字段 | 类型 | 必填 | 默认 | 值域/校验 | 索引 | 隐私 | 说明 |
|------|------|------|------|-----------|------|------|------|
| id | String | 系统 | UUID | | PK | L | |
| title | String | 是 | — | 1–80 字 | IDX | M | |
| startAt | Long | 是 | — | 有效时间戳 | 复合 IDX | M | |
| endAt | Long | 是 | — | 非全天：> startAt；全天：可为日末 | — | M | |
| isAllDay | Boolean | 是 | false | 全天时忽略钟表，按本地日 | — | M | |
| notes | String? | 否 | null | ≤ 2000 字 | — | M | |
| reminderOffsets | List\<Int\> | 否 | `[]` | 每项 0–10080；最多 3 | — | M | 相对 startAt |
| repeatFreq | Enum? | 否 | null | `DAILY`\|`WEEKLY`\|`WORKDAYS` | — | M | 空=不重复 |
| repeatUntil | Long? | 否 | null | ≥ startAt；与 repeatCount 至少一 | — | M | |
| repeatCount | Int? | 否 | null | 1–365；与 repeatUntil 至少一 | — | M | |
| source | Enum | 是 | MANUAL | | L | | |
| isDeleted | Boolean | 是 | false | | 复合 IDX | L | |
| createdAt / updatedAt | Long | 是 | now | | L | | |

**业务规则**

- 设置 `repeatFreq` 时，必须提供 `repeatUntil` 或 `repeatCount`（防无限重复）。
- `WORKDAYS` 仅周一至周五；不含节假日调休。
- 非全天且 `endAt - startAt > 7 天` → 警告但不强制（可提示改全天）。

## 5. EventException（日程重复例外）

表：`event_exceptions`

| 字段 | 类型 | 必填 | 默认 | 值域/校验 | 索引 | 隐私 | 说明 |
|------|------|------|------|-----------|------|------|------|
| id | String | 系统 | UUID | | PK | L | |
| eventId | String | 是 | — | 父事件存在 | 复合 IDX | L | |
| originalStartAt | Long | 是 | — | 命中某次展开 | 复合 IDX | M | 原实例开始时间 |
| isDeletedInstance | Boolean | 是 | false | true=删本次 | — | M | |
| overrideStartAt | Long? | 否 | null | 若改时间 | — | M | |
| overrideEndAt | Long? | 否 | null | > overrideStartAt | — | M | |
| overrideTitle | String? | 否 | null | 1–80 字 | — | M | |
| isDeleted | Boolean | 是 | false | | L | | |
| createdAt / updatedAt | Long | 是 | now | | L | | |

**业务规则**

- 同一 `(eventId, originalStartAt)` 最多一条未删例外。
- `isDeletedInstance = true` 时忽略 override 字段。

## 6. Todo（待办）

表：`todos`

| 字段 | 类型 | 必填 | 默认 | 值域/校验 | 索引 | 隐私 | 说明 |
|------|------|------|------|-----------|------|------|------|
| id | String | 系统 | UUID | | PK | L | |
| title | String | 是 | — | 1–80 字 | IDX | M | |
| dueAt | Long? | 否 | null | 可空；空=收件箱 | 复合 IDX | M | |
| notes | String? | 否 | null | ≤ 2000 字 | — | M | |
| isDone | Boolean | 是 | false | | 复合 IDX | M | |
| doneAt | Long? | 否 | null | isDone=true 时非空 | — | M | |
| reminderOffsets | List\<Int\> | 否 | `[]` | 相对 dueAt；无 due 时忽略 | — | M | |
| source | Enum | 是 | MANUAL | | L | | |
| isDeleted | Boolean | 是 | false | | IDX | L | |
| createdAt / updatedAt | Long | 是 | now | | L | | |

**业务规则**

- `complete_todo`：`isDone=true`，`doneAt=now`；再次 complete 幂等。
- 取消完成：MVP 可通过 `update_todo` 设 `isDone=false`（D4 支持）。

## 10. 字段 ↔ 工具参数名对照

| Course | name, teacher, location, weekday, periodStart, periodEnd, weeksSpec, isBiweekly, biweeklyOdd, reminderOffsets, colorToken | 同名 |
