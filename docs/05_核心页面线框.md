│ 〔区域 B：今日待办〕                    │

- 未到期待办：今日待办下方分组「即将到来」（按截止时间升序），保证未来截止的待办在截止前每天都在今日页可见

## 7. Agent 消息类型状态机

```text
[UserMessage]
      │
      ▼
[AssistantThinking] 〔可选短提示〕
      │
      ├─ 仅读查询 ──────────────► [AssistantText + 列表卡]
      │
      ├─ 低风险写 ──────────────► [ToolExecute] ─► [ResultCard]
      │                              │撤销
      │                              ▼
      │                          [UndoSnackbar]
      │
      ├─ 中风险写 ──► [ConfirmCard diff] ─确认─► [ToolExecute] ─► [ResultCard]
      │                    │取消
      │                    ▼
      │               [CancelledCard]
      │
      ├─ 高风险删（单）─► [ConfirmCard] ─► [ToolExecute soft-delete] ─► [ResultCard]
      │
      ├─ 高风险删（批）─► [ConfirmList] ─► [二次确认] ─► [ToolExecute] ─► [ResultCard]
      │
      └─ 解析失败/不确定 ─► [ClarifyQuestion] ─► 等待新 UserMessage
```

**卡片字段最小集**

| 卡片 | 必含 |
|------|------|
| ConfirmCard-创建 | 标题、绝对开始/结束、类型（日程/待办/课程） |
| ConfirmCard-diff | 变更前→变更后（字段级） |
| ConfirmList | 条目标题+时间，全选默认勾选 |
| ResultCard | 成功摘要、查看、撤销（若支持） |
| ClarifyQuestion | 2–3 个选项或明确反问句 |

## 14. 空态与错误态（最低要求）

| 场景 | 文案方向 |
|------|----------|
| 今日无数据 | 「今天没有安排」+ CTA |
| 无学期 | 课表/教学周引导配置 |
| 未配置 AI | 引导去 settings_ai |
| Agent 超时 | 「网络不稳定，请重试」 |
| 权限被拒 | 引导 OEM/系统设置 |
| 搜索无结果 | 「没有找到相关内容」 |
