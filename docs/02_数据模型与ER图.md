## 1. 建模原则

1. **本地唯一事实源**：一切日程/待办/课程定义存在本机 Room；Agent 只是入口。
2. **课程与日程分表**：Course 与 Event 不合并；日历用投影合成（§4）。
3. **软删除统一**：`isDeleted` 一票否决读取；物理清理策略 MVP 不做。
4. **绝对时间**：存 UTC 瞬时或 epoch millis；展示与「今天」按设备时区换算。字段逻辑类型在 D3 写清。
5. **可删可撤销**：写库路径必须支持 `restore`（至少对软删除）。

## 2. 实体清单

| 实体 | 表名（建议） | 职责 | 可软删 |
|------|----------------|------|--------|
| 学期 | `semesters` | 教学周期与教学周锚点 | 是 |
| 节次时段 | `period_slots` | 某学期第 N 节的钟表时间 | 是（随学期） |
| 课程 | `courses` | 课表定义 | 是 |
| 日程 | `events` | 用户日程（含重复） | 是 |
| 日程重复例外 | `event_exceptions` | 某实例删除/改期 | 是 |
| 待办 | `todos` | 任务与完成态 | 是 |
| 操作快照 | `undo_snapshots` | 支撑撤销（短窗口） | 到期物理删 |

> `event_exceptions` 为 MVP 重复「仅删除/改期本次」的最小支撑；不是调课表。调课例外仍用额外 Event（见 D1 Q1）。

## 4. 关系与基数

| 关系 | 基数 | 说明 |
|------|------|------|
| Semester → PeriodSlot | 1..N | 一学期多节次；删除学期 → 节次与课程不可见（软删级联在 Repository） |
| Semester → Course | 1..N | 课程必须挂学期 |
| Event → EventException | 0..N | 仅重复事件可能有例外 |
| UndoSnapshot → 任一实体 | N..0/1 | 快照记录 `entityType + entityId`，弱引用，不做 FK 级联 |

**无 FK 指向 Course 的 Occurrence**：Occurrence 不是表。

## 5. 投影规则（Agenda）

某本地日 `D` 的 Agenda：

```text
agenda(D) =
    eventsActiveOn(D)                          # 含重复展开且未被 exception 删除
  + courseOccurrencesOn(D)                     # 由 courses × period_slots 计算
  + todosForDay(D)                             # dueAt 落在 D，或 今日收件箱策略见下
```

### 5.1 事件展开

对 `repeat_freq = DAILY | WEEKLY | WORKDAYS`：

- `DAILY`：`start_at.date <= D <= repeat_until` 且按间隔 1 天
- `WEEKLY`：与事件原始星期几相同
- `WORKDAYS`：D 为周一至周五
- 若存在 `event_exceptions` 匹配 `(event_id, D 的原始 occurrence start)`：
  - `is_deleted_instance = true` → 不展示
  - 否则用 override 时间/标题展示

无重复：`start_at` 的本地日 = D 才展示。

### 5.2 课程投影

```text
weekIndex(D) = floor((D - week1Monday) / 7) + 1   # D 取该日所在周的周一比较时按周对齐
若 weekIndex < 1 或 semester 未覆盖 D → 不投影
若 weekday(D) != course.weekday → 不投影
若 weekIndex 不在 weeks_spec → 不投影
若 is_biweekly 且 (weekIndex 奇偶) 与 biweekly_odd 不符 → 不投影
否则：
  start = D.date + period_slots[period_start].start
  end   = D.date + period_slots[period_end].end
  生成 CourseOccurrence(只读)
```

### 5.3 待办展示

MVP：

- 日视图「今日待办」= `dueAt` 本地日 = D 的未完成待办 + **无截止**的未完成待办（收件箱）
- 有截止且已过期未完成 → 同时出现在「已逾期」分组（D5）

## 6. 软删除与撤销

### 6.1 软删除

- 所有列表查询默认 `isDeleted = false`
- 删除 = `isDeleted = true` + 写 `undo_snapshots`
- 恢复 = `isDeleted = false`

### 6.2 撤销快照

| 字段语义 | 说明 |
|----------|------|
| entityType | `event` / `todo` / `course` / `semester` |
| action | `delete` / `update` / `create` |
| payload | 操作前完整实体 JSON（create 则存新 id 以便 delete-on-undo） |
| expires_at | 默认创建后 10 分钟；到期可物理删快照 |

**原则**：撤销走本地快照，**不要求**再调用大模型。

## 7. 重复与「仅本次」

| 用户意图 | 数据路径 |
|----------|----------|
| 改本次时间 | 写 `event_exceptions`（override 时间），保留原系列 |
| 删本次 | 写 `event_exceptions.is_deleted_instance = true` |
| 改整个系列规则 | MVP 更新父 Event 的 repeat 字段；不追溯已出现例外 |

## 8. 索引与查询场景

| 场景 | 建议索引 |
|------|----------|
| 打开今日 Agenda | `events(is_deleted, start_at)`；`courses(is_deleted, semester_id, weekday)`；`todos(is_deleted, is_done, due_at)` |
| 周视图 | 同上按 `start_at` 范围 |
| 搜索标题 | `events(is_deleted, title)`；`todos(...)`；`courses(...)`（MVP 可用 LIKE，量小） |
| 当前学期 | `semesters(is_deleted, is_current)` |
| 例外查找 | `event_exceptions(event_id, original_start_at)` |

---

## 9. 明确不建模（MVP）

- 参与人、附件、地点地图、颜色自定义（仅 color token）
- 多用户/账号/云同步
- 系统 Calendar Provider 往返
- 课程调课专用表（用额外 Event）
- 硬删与归档生命周期
